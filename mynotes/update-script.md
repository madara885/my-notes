Создайте файл `update_apps.sh` и вставьте код:

#!/bin/bash

echo -e "\e[1;36m=== Старт обновления системы Linux (APT) ===\e[0m"

echo -e "\n\e[1;33m[1/4] Обновление списков пакетов...\e[0m"
sudo apt update

echo -e "\n\e[1;33m[2/4] Установка доступных обновлений...\e[0m"
sudo apt upgrade -y

echo -e "\n\e[1;33m[3/4] Очистка неиспользуемых зависимостей...\e[0m"
sudo apt autoremove -y`

echo -e "\n\e[1;33m[4/4] Очистка кэша пакетов...\e[0m"`
sudo apt clean

echo -e "\n\e[1;32m=== Все приложения и система успешно обновлены! ===\e[0m"

Как запустить: Выдайте права командой `chmod +x update_apps.sh` и запустите: `./update_apps.sh.` Скрипт попросит пароль администратора (sudo)
